# 帐篷 Tents

一个基于 Web 的帐篷（Tents）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5175`）。

## 游戏规则

官方语义是「树–帐篷存在完整的一对一配对」：

- 每棵树最终配一顶上下左右相邻的帐篷，每顶帐篷最终配一棵上下左右相邻的树
- 帐篷可以同时挨多棵树、树也可以同时挨多顶帐篷，只要存在一组完整的一对一匹配即可
- 任意两个帐篷不能相邻，正交或斜角都不行
- 棋盘外数字等于对应行或列的帐篷数

> 注意：这不是「每棵树/每顶帐篷在局部恰好只挨一个」的严格规则。校验与求解都用
> 树–帐篷二分图匹配来判断（见 `src/matching.ts`）。

## 逻辑解题定式

`L` 键的逻辑解题不做穷举、不做假设，只用一整套**标准定式**从当前盘面推出必然结论，
每一步都带人类可读的理由。规则按语义分成两层，反复跑到不动点：

| 规则 | 类型 | 内容 |
|------|------|------|
| 帐篷周围 → 草地 | 局部 | 帐篷八邻（含斜角）的空地都不能再放帐篷 |
| 不挨树 → 草地 | 局部 | 四邻没有树的空地配不上任何帐篷，必是草地 |
| 树只剩唯一格 → 帐篷 | 局部 | 某棵树正交相邻只剩一个可放格时，那格必是帐篷 |
| 行列线索达标 → 草地 | 局部 | 某行/列帐篷数已等于线索，其余空地全标草地 |
| 行列线解法 | 局部 | 把一行/列当一排格子做 DP，枚举满足「线索数 + 帐篷不相邻」的所有摆法；某格在所有摆法里都必是帐篷/草地就直接定下来（缺口顶满、连续段隔一格等定式都收在这里） |
| 树的行列归属 | 局部 | 某棵树的候选格全在同一行/列 ⇒ 它的帐篷一定在那里；该行/列被这种树占满座位时，其余空地必是草地 |
| 匹配定式 | 全局 | 把所有树 ↔ 可放帐篷格建成二分图，求一组覆盖全部树的匹配；某格在**每一套**完整匹配里都被占用 ⇒ 必是帐篷（Hall 集合约束的落地）；覆盖不了 ⇒ 报匹配矛盾 |
| 相邻两行/列联合线解法 | 全局 | 把相邻两行（列）当成 2×L 条带做 DP，同时满足两行线索、行内帐篷不相邻、以及上下/斜角互斥；单行看不出的斜角约束在这里收掉 |

全局定式只在局部定式推不动时才跑，避免每轮都做匹配/条带 DP；条带 DP 只对
≤ 20×20 的题面启用（内置题最大 10×10，开销可忽略）。

所有结论都是「在所有满足已确定格子的完整解里都成立」的必然结论，所以不会误推。
`npm run check` 除了唯一解校验，还会从空盘跑一遍逻辑解题：
**每条推理都必须和参考解一致**（规则不健全会直接报错），并打印每题的步数与是否可推满。

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 帐篷 → 草地 → 空 |
| 右键点格 | 反向循环 / 清除 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：标准定式逐帧回放（匹配 / 行列线解法 / 斜角互斥等），显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移
- **自定义题**：在侧边栏点击种树，行列线索留空自行推理；载入题板即存入题库，之后可编辑或删除

## 技术栈

## 图片导入

`npm run import-image -- <图片路径>` 可以自动识别帐篷（Tents）题图：黑线投影定位网格，按格子背景色（浅绿）识别树，盘外数字用「行/列槽位切分 + 单字多字体模板匹配」OCR——左侧读行线索、上方读列线索，数字按中心归到最近的槽位，挤在一起的两个数字按竖直投影拆开，浅灰的行列坐标编号会被阈值过滤。

```bash
npm run import-image -- 题图.png --dry                        # 只识别与预览
npm run import-image -- 题图.png --name "我的帐篷" --append      # 追加到题库
npm run import-image -- 题图.png --append --verify            # 追加前做唯一解检查
```

| 参数 | 说明 |
|------|------|
| `--size N` / `--width W --height H` | 覆盖棋盘尺寸 |
| `--rows "a,b,…"` / `--cols "a,b,…"` | 覆盖行/列线索：数字 = 帐篷数，`?` = 保留 OCR 结果，空 / `x` = 该行（列）无数字 |
| `--map <JSON文件或内联JSON>` | 人工修正整份题面：`{ width, height, trees, rows, cols }`，未给的字段保留识别结果；`trees` 用 `#`（或 `o`）表示树，长度 W×H |
| `--name` / `--id` / `--series` | 题库名字 / id / 分组 |
| `--append` / `--verify` / `--dry` / `--debug` | 写入题库 / 唯一解检查 / 只识别 / 打印逐条线索的置信度 |

识别后会报告行/列线索命中数、数字字块数、最接近字体与误差，以及缺失的行号/列号和低置信条目（均按 1 起编号），方便用 `--rows` / `--cols` / `--map` 定点修正；行列合计还会和树数交叉校验（每棵树配一个帐篷，两者应相等）。

**已知限制**

- 30×30 月度大题已可用：`month.png` 的 30 行 + 30 列线索全部识别（65 个数字字块），行列合计 180 = 树数 180；树位与线索和题目来源的官方数据逐格一致。
- `--verify` 按官方匹配语义检查（树–帐篷二分图一一配对）。`month.png` 在 `--verify` 下**唯一解通过**（5998 节点 / 约 0.9s），解里有 53 顶帐篷同时挨 2 棵树——旧版「每棵树/每顶帐篷局部恰好只挨一个」的严格规则会把它误判为无解，现已修正。
- `--verify` 对远超 30×30 或树极密的题面仍可能超出回溯预算而超时，只给警告、不阻塞 `--append`。
- 数字识别依赖深色文字与清晰度；低分辨率图片请结合 `--debug` 的逐条误差判断，必要时人工覆盖。

## 题板尺寸与形状支持

- **题面模型**：树位图 + 行/列帐篷数线索，`width × height`，宽高完全独立；
  渲染、命中、校验、唯一性求解、逻辑解题都按宽高分别计算。
- **内置题库**：6×6～10×10 正方形。
- **自定义题板**：宽 3–40、高 3–40，任意非正方形（点树、填行列数字）。
- **识图导入**：30×30 大图自动识别（360 个树格、行列线索全命中）。
- **异形棋盘**：不支持（每棵树/每个帐篷都限制在完整矩形格阵上；没有棋盘外空格语义）。
- **验证**：`npm run build`、`npm run check` 通过；`check` 会逐题从空盘跑逻辑解题并对照参考解，
  内置 6 题全部「逻辑可推满 + 0 冲突」（6×6 28 步、7×7 38 步、8×8 49 步、9×9 62 步、10×10 77 步）。
  另用生成器临时生成 6×8 矩形题验证过「参考解合法 + 唯一解 + 逻辑解题完整推出」，题库未改动。
- **限制**：40×40 级题的回溯求解可能超时（有预算上限）；线索是盘外数字，自定义题板需逐行/列录入；
  逻辑解题的匹配/条带定式在 > 20×20 的题面上会跳过（保证交互不卡），此时只剩局部定式与「需假设」提示。
