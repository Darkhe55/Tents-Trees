# 帐篷 Tents

一个基于 Web 的帐篷（Tents）谜题游戏，原生 SVG 渲染，内置逻辑解题器接口。

## 在线体验

克隆后运行：

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5175`）。

## 游戏规则

把帐篷放到树旁边：

- 每棵树恰好配一个正交相邻（上下左右）的帐篷
- 每个帐篷恰好只挨一棵树
- 任意两个帐篷不能正交相邻
- 棋盘外的数字，等于对应行 / 列的帐篷数

## 功能

- **题库**：内置 6 道题，从 6×6 入门到 10×10 挑战，均校验唯一解
- **自定义题**：在侧边栏点击种树，载入后即可游玩（行列线索留空自己推）
- **逻辑解题**：规则引擎接口已预留（`src/logic.ts`）， UI 按钮已接通
- **音效特效**：搭帐篷播放弦振拨弦 + 形变抖动，标草地播放水滴 + 涟漪
- **实时校验**：帐篷数不对的树、挨错树的帐篷、挨在一起的帐篷、不符的行列数字都会标红
- **进度保存**：自动保存每道题的进度，刷新不丢失
- **撤销/重做**：按手势分组，一次拖拽涂写只需一步撤销
- **提示一格 / 显示解**、悬停高亮、滚轮缩放、中键平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage 存储进度

## 项目结构

```
src/
  main.ts         主逻辑：UI、交互、音效调度
  render.ts       SVG 棋盘渲染、命中检测、缩放度量
  logic.ts        逻辑解题规则引擎（预留接口）
  solver.ts       回溯求解器（唯一解校验）
  audio.ts        Web Audio 音效合成（拨弦 / 水滴）
  fx.ts           落子特效（弦振 / 形变 / 涟漪）
  puzzles.ts      题库加载
  puzzles-data.ts 静态题库数据（自动生成）
  state.ts        棋盘状态与邻格计算
  validate.ts     解的合法性校验（四条规则）
  types.ts        共享类型
```
