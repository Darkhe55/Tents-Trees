# 帐篷 Tents

一个基于 Web 的帐篷（Tents）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5175`）。

## 游戏规则

- 每棵树恰好配一个上下左右相邻的帐篷
- 每个帐篷恰好只挨一棵树
- 任意两个帐篷不能相邻，正交或斜角都不行
- 棋盘外数字等于对应行或列的帐篷数

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 帐篷 → 草地 → 空 |
| 右键点格 | 反向循环 / 清除 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移
- **自定义题**：在侧边栏点击种树，行列线索留空自行推理；载入题板即存入题库，之后可编辑或删除
- **逻辑解题**：规则引擎逐步推出帐篷与草地，按钮可直接调用

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage 存储进度与题库

```bash
npm run build     # tsc --noEmit + vite build
npm run gen       # 重新生成题库
npm run check     # 审计题库
```
