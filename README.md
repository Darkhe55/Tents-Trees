# 帐篷 · Tents

网页版「帐篷」逻辑谜题。Vite + TypeScript + 原生 SVG，无框架。

## 玩法

- 每棵树配一个**相邻**帐篷，每个帐篷只挨一棵树
- 帐篷之间**不能相邻**
- 棋盘外数字 = 对应行/列的帐篷数

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5175
```

## 操作

| 操作 | 说明 |
|------|------|
| 左键点空地 | 循环：空 → 帐篷 → 草地 → 空 |
| 右键点空地 | 反向循环 |
| 按住左键拖拽 | 连续涂同一个状态 |
| 滚轮 / 中键拖拽 | 缩放 / 平移 |
| `Z` / `Shift+Z` | 撤销 / 重做 |
| `C` / `H` / `S` / `Esc` | 检查 / 提示一格 / 显示解 / 清空 |
| `R` / `L` | 随机抽题 / 逻辑解题 |

「草地」是你自己标的「这里没帐篷」，方便记思路。

## 功能

- 6 道内置题（6×6 到 10×10），全部经过**唯一解**校验
- 实时校验：帐篷数不对的树、挨错树的帐篷、挨在一起的帐篷、不符的行列数字都会标红
- 提示一格 / 显示参考解（可撤销）、撤销重做按手势分组
- 自定义题板：自己种树，行列线索留空自己推
- 进度自动存 localStorage；悬停高亮、滚轮缩放、中键平移
